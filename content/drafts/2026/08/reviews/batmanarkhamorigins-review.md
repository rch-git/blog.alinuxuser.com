This game was developed by WB Games Montreal, while Rocksteady was busy working on Arkham Knight. This game felt like a slightly buggy, less polished prequel of Arkham City.

Gameplay is very similar to Arkham City. There is a lot of side content in the game. I did not go through all that content. I did a couple of the side missions. I mainly stuck to the story missions.

The entire game is set during Christmas. The story takes place during the night on Christmas eve. I think it all happens over a period of 12 hours in the game universe. There are some great set pieces. Enjoyed those for sure. Combat is very much the same, but there are definitely some sections where the game is buggy. I had to play this in DX10 mode.

Boss fights were boring for me. The Bane fight especially is tedious because you have to fight him multiple times. This is just pure gameplay padding. 

Story was interesting. This game focuses on when Batman meets Joker for the first time. 

It is very evident that this game was made to fill in the gap while Rocksteady was busy working on the final game in the trilogy. 

As a younger Bruce Wayne, you are only a few years into being Batman. The police still do not trust you. You gain Jim Gordon's trust by the end of the game.

This game is often forgotten when talking about Batman games; they are referred to as the Arkham trilogy. This game was made to fill the gap, and in some ways, it shows. 

I would recommend buying this game if you finished all the mainline games, and found this for under $5. There is some fun to be had, but you are not missing anything if you never play this game. There is nothing special about this game. 

Game is made with console in mind. Gameplay, UI are console centric. This is not a horrible PC port, but its definitely not made the PC in mind. Its an annoying trend with AAA games.
