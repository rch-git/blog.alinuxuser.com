Rise: Son of Rome made me realize that life is too short for me to play mediocre games. No more. I am going to only play good games from now on. 

This game could have been amazing, but as usual, design choices made this an extremely mediocre game. As of this writing, the game is on sale for $2.89. I think this game is worth about $1. Might sound harsh, but that's how I feel. This game turned into a chore. The only positive thing about this game is that its short. My Steam page shows that I played it for 8.3 hours. 

Maybe about 1hr of that is spent troubleshooting technical issues. There is a framerate and stuttering problem. I was getting ~30 FPS on my machine (i7 12700K, GeForce RTX 3080Ti, 2560x1440). I have a high refresh rate monitor, and I thought this might be the reason the game is having a spasm. So I installed it on my retro machine (i7 4700k, GeForce 1070Ti), and it had the same problem. 

Started searching online. There are some tweaks that need to be applied to the configuration file, and also "Low Latency Mode" in Nvidia app needed to be set to Ultra. This resolved the problems, and I was able to play it on my Alderlake machine.
